# Estação Horizonte Cultural

Projeto acadêmico desenvolvido em HTML para apresentar um espaço cultural, sua programação e um formulário de interesse nas atividades.

## Páginas

- **Início:** apresentação do espaço e destaques das atividades.
- **Programação:** tabela com dias, horários, espaços e vagas.
- **Inscrição:** formulário para demonstrar o registro de interesse.

## Tecnologia utilizada

- HTML5

## Como visualizar

1. Clique em Code → Download ZIP.
2. Extraia os arquivos.
3. Abra o arquivo index.html no navegador.

## Aprendizados

Prática de estruturação de páginas em HTML, navegação entre arquivos, imagens, tabelas e formulários.

## Status

Projeto em desenvolvimento, com ajustes de estrutura, validação do formulário e revisão de textos pendentes.

O formulário é demonstrativo e não possui integração com um servidor para registrar inscrições.
